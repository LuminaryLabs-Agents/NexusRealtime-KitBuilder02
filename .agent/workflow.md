# Agent Workflow

1. Inspect status, the agent brain, manifest, project record, source, examples, and tests.
2. State the owning kit and the lifecycle evidence required.
3. Make one bounded change without crossing domain or adapter boundaries.
4. Run `npm run check` and the closest live or doctor check.
5. Review changed artifacts and worktree cleanliness.
6. Record durable lessons in the existing KitBuilder agent brain only when supported by evidence.
7. Advance lifecycle state only through the repository command and only when its gate passes.

Completion reports must name changed files, commands, observed behavior, and remaining limitations. Tests do not authorize public tunnels or kit promotion.
