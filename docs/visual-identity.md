# Visual Identity

## Intent

The identity represents five bounded capabilities joining into one resilient fabric: rooms, routing, local-model jobs, live mirroring, and optional tunneling. The flat paper-collage style keeps the system understandable and avoids implying unsupported production infrastructure.

## Assets

`docs/assets/brand/` contains the original sources, transparent logo, PNG sizes, editable mask, normalized cover, social card, manifest, and asset guide.

- Preserve the logo's transparent margin.
- Keep every system element fully visible; do not crop the cover flow.
- Use the mask for controlled recoloring.
- Do not stretch, rotate, add effects, or place the logo on low-contrast imagery.
